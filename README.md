# JWT Security Practice
Spring Boot + Spring Security + JWT + MySQL. Roles: USER, ADMIN, SUPER_ADMIN.
Access token: 10 minutes. Refresh token: 20 minutes.
No JUnit/Mockito test implementation is included; test dependencies are present for practice.

MySQL defaults: root/root. Change application.properties if needed.
Seed users: user@example.com/User@123, admin@example.com/Admin@123, superadmin@example.com/SuperAdmin@123.
